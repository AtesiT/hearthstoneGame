# 04. УПРАВЛЕНИЕ

## Меню

- **Ваше имя** — 3–16 символов (буквы, цифры, `_`); сохраняется в localStorage.
- **Создать комнату** — хост новой комнаты (код на экране ожидания).
- **Лобби · Присоединиться** — список комнат + вход по коду.
- **Коллекция карт** — все 30 карт: фильтры по типу, 3 сортировки,
  клик — детальная карта (Esc / клик вне — закрыть).
- **⚙ Настройки** — громкость музыки (0–100), звуки, подсказки
  (localStorage, применяются сразу).
- **Esc** — в меню/лобби возврат в меню.

## Лобби и ожидание

- «Войти» в списке / «Войти по коду» (Enter работает в поле кода).
- **Готов / Снять готовность** — оба готовы → у хоста появляется «Начать матч».
- **Копировать** — код комнаты в буфер.
- **Покинуть** — выйти из комнаты.

## Матч

- **Клик по карте в руке** — выбрать; валидные цели подсвечиваются
  (сервер присылает список, клиент только подсвечивает).
  Клик по цели — сыграть; **ПКМ / Esc** — отмена; повторный клик по карте —
  сыграть без цели (если карта её не требует).
- **Клик по своему существу** — выбрать атаку; клик по подсвеченной цели —
  атака. Оружие — клик по **своему герою**, затем цель.
- **Завершить ход** — кнопка справа внизу (или когда действий нет).
- **Панель эмоций** (8 лиц) — над рукой; эмоция видна обоим (пузырь над
  портретом), троттлинг 1/с.
- **☰ Лог** (или клавиша **Л**) — выдвигающийся боевой лог.
- **♪** — звук вкл/выкл.
- Наведение на существо/карту — тултип (статы, текст, словарь ключевых слов).
- **ПОБЕДА/ПОРАЖЕНИЕ** — «В лобби» (rematch в той же комнате).

## Подсказки (можно выключить в настройках)

- «Действий нет — завершите ход», «Поле полное (7/7)»,
  «Карты сыграть нельзя (мана)», «Выберите цель (ПКМ / Esc — отмена)».

## Состояния

- **Оппонент отключился** — оверлей с отсчётом; матч остановлен, grace 30 с.
  Возврат — `opp_back`, без потери состояния (resync-снапшот).
- **Соединение потеряно** — автореконнект до 10 попыток × 1 с;
  при наличии комнаты — reconnect по токену.
- **Вытеснение** — токен заняли на другом устройстве.

## Клавиатура

| Клавиша | Действие |
|---|---|
| Esc | снять выбор карты / закрыть коллекцию / в меню из лобби |
| Л / L | боевой лог |
| Enter | создать комнату (в поле ника) / войти (в поле кода) |
